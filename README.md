# Система учёта иностранных студентов ННГАСУ

Настольное приложение для ведения базы данных иностранных граждан,
обучающихся в ННГАСУ, с поддержкой ролей доступа, шаблонами Word и табличными отчётами.

---

## Структура проекта

```
student_system/
├── main.py                 ← Точка входа — запускайте это
├── config.py               ← config.ini, путь к БД, ключ SQLCipher
├── database.py             ← Работа с БД (CRUD, журнал)
├── auth.py                 ← Хэширование паролей (PBKDF2-SHA256)
├── template_engine.py      ← Шаблоны .docx с метками {{поле}}, папки templates/ и exports/
├── requirements.txt        ← Зависимости
├── templates/              ← Файлы-шаблоны Word (.docx); при сборке exe подключаются через main.spec
├── data/
│   └── students.db         ← База по умолчанию (создаётся после настройки)
├── exports/                ← Сгенерированные из шаблонов Word-файлы (рядом с приложением / exe)
└── ui/
    ├── login_window.py     ← Экран входа
    ├── main_window.py      ← Главное окно (список студентов)
    ├── student_form.py     ← Форма добавления/редактирования (все 20 полей)
    ├── admin_panel.py      ← Панель администратора (пользователи, справочник стран)
    ├── templates_window.py ← Шаблоны Word: список, заполнение по студенту
    ├── table_reports_window.py ← Табличные текстовые отчёты
    └── settings_window.py  ← Путь к БД и первичная настройка
```

## Установка и запуск

### 1. Требования
- Python 3.10 или новее
- Windows / macOS / Linux

### 2. Установить зависимости
```bash
pip install -r requirements.txt
```

(вручную: `python-docx`, при необходимости шифрования БД — `sqlcipher3-binary`)

### 3. Запустить
```bash
cd student_system
python main.py
```

При первом запуске откроется мастер настройки пути к базе данных. Файл `config.ini` создаётся рядом с `main.py` (или рядом с `.exe` после сборки PyInstaller).

### Первый вход (учётные данные по умолчанию)
| Логин | Пароль   | Роль          |
|-------|----------|---------------|
| admin | admin123 | Администратор |

> ⚠️ **Сразу смените пароль администратора после первого входа!**

## Роли пользователей

| Роль           | Возможности                                                         |
|----------------|---------------------------------------------------------------------|
| **admin**      | Только управление пользователями и справочником стран               |
| **operator**   | Добавление, редактирование, удаление студентов; шаблоны Word; табличные отчёты |
| **viewer**     | Просмотр данных; шаблоны Word; табличные отчёты (без изменения студентов)   |

Количество учётных записей не ограничено.

## Word (шаблоны)

- В меню **«Шаблоны Word»** отображаются файлы `.docx` из рабочей папки `templates/` (она создаётся рядом с приложением; при первом открытии окна туда копируются шаблоны из комплекта сборки).
- В документе используются метки вида `{{фио}}`, `{{гражданство}}` и т.д. (список меток — в интерфейсе окна шаблонов).
- Готовые файлы сохраняются в папку **`exports/`** рядом с `main.py` или с `.exe`.

Сборка **PyInstaller**: в `main.spec` указано включение каталога `templates/` в дистрибутив (`datas`).

## Табличные отчёты

Окно **«Табличные отчёты»** (кнопка на главной панели):

- **Все студенты** — сводная таблица в текстовом виде  
- **Только выбранные** — по списку слева в окне отчётов  
- **Истекающие визы** — виза истекает в течение 30 дней  
- **Журнал действий** — последние записи (для admin и operator)

## Схема базы данных

```
countries       — справочник гражданств
users           — пользователи системы
students        — основная таблица (все 20 полей)
audit_log       — журнал действий
```

### Почему не однотабличная?

- `countries` вынесена в отдельный справочник:
  - исключает опечатки в названии страны
  - легко добавлять новые страны
  - удобна для фильтрации/поиска по гражданству
- `audit_log` — отдельная таблица для журналирования (логи не смешиваются с данными)
- `users` — отдельная таблица для управления доступом
- Основная таблица `students` хранит все 20 полей в денормализованном виде —
  это оправдано, так как все поля принадлежат одной сущности (студент)
  и поиск по ним ведётся совместно.

## Безопасность паролей

Пароли хранятся в БД как `PBKDF2-SHA256(password + salt, iterations=100_000)`.
Сам пароль в БД **не хранится**.

## Частые вопросы

**Q: Где хранится база данных?**  
A: Путь задаётся в `config.ini` (ключ `[database]` → `path`). По умолчанию это `data/students.db` относительно папки приложения. При установленном `sqlcipher3-binary` файл шифруется SQLCipher.

**Q: Как сделать резервную копию?**  
A: Скопируйте файл базы по пути из настроек и при необходимости `config.ini` (в нём ключ шифрования).

**Q: Заполнение Word-шаблонов не работает.**  
A: Убедитесь, что установлен `python-docx`: `pip install python-docx`

**Q: Как добавить новую страну?**  
A: В форме студента — кнопка «+ Добавить страну». Или через панель администратора.
