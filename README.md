# Система учёта иностранных студентов ННГАСУ

Настольное приложение для ведения базы данных иностранных граждан,
обучающихся в ННГАСУ, с поддержкой ролей доступа и генерацией Word-документов.

---

## Структура проекта

```
student_system/
├── main.py              ← Точка входа — запускайте это
├── database.py          ← Работа с SQLite (все CRUD-операции)
├── auth.py              ← Хэширование паролей (PBKDF2-SHA256)
├── word_templates.py    ← Генерация Word-документов (Справка, Визовая анкета)
├── requirements.txt     ← Зависимости
├── data/
│   └── students.db      ← База данных (создаётся автоматически)
├── exports/             ← Сгенерированные Word-файлы
└── ui/
    ├── login_window.py  ← Экран входа
    ├── main_window.py   ← Главное окно (список студентов)
    ├── student_form.py  ← Форма добавления/редактирования (все 20 полей)
    ├── admin_panel.py   ← Панель администратора (управление пользователями)
    └── reports_window.py← Отчёты и экспорт в Word
```

## Установка и запуск

### 1. Требования
- Python 3.10 или новее
- Windows / macOS / Linux

### 2. Установить зависимости
```bash
pip install python-docx
```

### 3. Запустить
```bash
cd student_system
python main.py
```

## Отчёты

- **Все студенты** — сводная таблица в текстовом виде
- **Истекающие визы** — студенты, у которых виза истекает ≤ 30 дней
- **Журнал действий** — лог всех операций (входы, добавления, удаления)

---

## Схема базы данных

```
countries       — справочник гражданств
users           — пользователи системы (до 10)
students        — основная таблица (все 20 полей)
audit_log       — журнал действий
```

### Почему не однотабличная?

- `countries` вынесена в отдельный справочник:
  - исключает опечатки в названии страны
  - легко добавлять новые страны
  - удобна для фильтрации/поиска по гражданству
- `audit_log` — отдельная таблица для журналирования (логи не смешиваются с данными)
- `users` — отдельная таблица для управления доступом
- Основная таблица `students` хранит все 20 полей в денормализованном виде —
  это оправдано, так как все поля принадлежат одной сущности (студент)
  и поиск по ним ведётся совместно.

---

## Безопасность паролей

Пароли хранятся в БД как `PBKDF2-SHA256(password + salt, iterations=100_000)`.
Сам пароль в БД **не хранится**.

## Частые вопросы

**Q: Где хранится база данных?**  
A: `student_system/data/students.db` — обычный SQLite-файл, можно открыть через DB Browser for SQLite.

**Q: Как сделать резервную копию?**  
A: Просто скопируйте файл `data/students.db`.

**Q: Word-экспорт не работает.**  
A: Убедитесь, что установлен `python-docx`: `pip install python-docx`

**Q: Как добавить новую страну?**  
A: В форме студента — кнопка «+ Добавить страну». Или через панель администратора.
